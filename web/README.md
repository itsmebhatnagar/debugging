## C code execution

The arena supports C only. Code is compiled and run by the configured Judge0 service in its execution sandbox; set `JUDGE0_API_URL` to the Judge0 base URL. The app selects the highest GCC C version advertised by that Judge0 instance for each run and displays the selected version, compiler output, program output, and errors in the terminal. Ensure the Judge0 instance is configured with execution time and memory limits.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
